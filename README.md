## À propos

Étudiant en double cursus **CPE Lyon ETI** (Électronique, Télécommunications, Informatique) + **Licence 3 de Mathématiques** à l'Université Claude Bernard Lyon 1. Passionné par l'intersection entre **traitement du signal**, **traitement d'image**, **machine learning** et **mathématiques appliquées**.

Mes projets reflètent cette double identité : j'aime poser la théorie maths *avant* de coder, et utiliser des cas simples (régression, classification audio, approximation polynomiale) pour comprendre ce qui se passe vraiment dans une descente de gradient, une SVD ou un autograd.

📍 Lyon, France &nbsp;·&nbsp; 🎯 **Stage Machine Learning & Signal** — AMAH (mission Legrand) — Juillet – Septembre 2026
